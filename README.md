# abnt-latex-skill

Skill para montar trabalhos acadêmicos em LaTeX seguindo as normas ABNT, com a classe `facom-ufu-abntex2` (UFU/FACOM), baseada em `abntex2`.

## Conteúdo

- `SKILL.md`: instruções de uso, regras da classe e armadilhas já encontradas.
- `templates/`: projeto de exemplo (`main.tex` com campos entre colchetes, capítulos de exemplo e `references.bib` com acentos em LaTeX).

## Uso no Overleaf

1. Copie a pasta `templates/` inteira (inclui `facom-ufu-abntex2.cls`).
2. Mantenha todos os arquivos na mesma pasta.
3. Preencha os campos entre colchetes em `main.tex`.
4. Compacte a pasta em `.zip` e importe no Overleaf (New Project → Upload Project).
5. Compile com pdfLaTeX.
